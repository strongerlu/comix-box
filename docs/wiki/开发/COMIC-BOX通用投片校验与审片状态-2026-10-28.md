# COMIC-BOX 通用投片校验与审片状态

## 范围

按用户要求，从共用流程改进，不为样片写入人物、道具数量、场景或固定秒数。本次修改 Windows 共用 TypeScript 调度与 Vue 面板，保留用户累计改动。没有新增云端文字、图片或视频生成，没有核对实际费用，没有更换服务、凭据或安装包。

## 根因及处理

1. 完成阶段不等于内容有效。`episodeTextStatus` 原来只认阶段及时间范围，显式 blocked 记录可能被认作可复用；现在 blocked 保留原因，共用片段计划校验拒绝空列表、无效/重复提示词路径、重复或无效参考资产、时间断档/重叠及登记时长不符。
2. 首次投片需要全体预检。全部片段先完成提示词读取、非空检查、参考图就绪/定义/顺序/正文图号和模型约束校验，任一失败不提交这一批视频；错误标出段号和路径。H3、Seedance 使用各自语法，纯文生的空 refs 仍然有效。保留既有模型时长向上取整、拼接裁切及旧检查点兼容，不强加新必填字段。
3. 审片布尔值没有绑定产物。现在用有序片段的路径、生成指纹、任务号与视频路径计算版本键；仅同版本人工确认可复用。重做后确认失效；审片期间尚有任务未完成则继续等待。旧记录不冒充新版本确认，原已完成集不自动重做。
4. 界面把完成与质量混用。提示词就绪、已拼接但未审片、已拼接且人工确认、旧审片状态未记录分别显示；不将 H3/Seedance 型号命名为测试/正式质量等级，保留另出一版能力。审片提示覆盖因果、人物道具、空间、动作与结尾、声画，不宣称程序自动判断了画面。
5. 读取提示词失败后，错误文字曾写入可保存正文。审图/审片现在共用编辑器，错误与正文分离；失败、读取中和空正文禁止保存，提供重新读取；切换目标、关闭或换集使旧异步响应失效，防止覆盖新内容。保存仍由用户明确触发，读取重试不调用生成。

## 验证方法与边界

新增根因回归先红后绿：第二段空正文或重复路径时零提交、两种格式未登记图号与重复资产零提交、显式 blocked 不复用、同版本审片复用/换版本重审、编辑读取失败/恢复/空白/加载中/乱序响应/取消。完成标签覆盖文字、跳过审片、旧记录和版本确认。
