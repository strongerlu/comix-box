# COMIC-BOX 本地 ComfyUI 视频模型配置

> 2026-10-29，Windows 开发版。通用文生视频配置已接入；真实 GPU 验证记录见下文。设置保存和 MCP 握手不等于生成成功。

## 配置与执行合同

设置 → 模型与服务 → ComfyUI → 本地视频模型。新增显示名称，导入 ComfyUI「导出(API)」JSON，填写提示词和可选参数的 `节点ID.输入名`，保存后在创作面板的视频模型列表「本地 ComfyUI」组选择。

连接地址与依赖复用设置 → MCP → ComfyUI（官方）。固定依赖为 comfy-mcp 0.10.0、comfy-cli 1.20.0；可填写虚拟环境可执行文件完整路径。本期官方连接只支持本机/局域网裸 HTTP；不自动降级地址，不把本地生成转发到云端。

配置不固定 H3、服务器 IP 或节点编号。权重名称、采样器、LoRA、步数、输出节点及连接保持导入工作流的实际值。当前新增配置只声明文生视频；未接入参考图、首帧或尾帧绑定，不把这些能力标为支持。旧云端和既有本地型号保留。

## 参数约束

- 提示词必须绑定字符串输入。时长绑定必须为秒数，不能直接绑定帧数；保留工作流原有的秒数到帧数换算。
- 最短/最长时长为正数，最长不超过3600秒；没有时长绑定时两者必须相同，表示工作流固定时长。这里填写的是工作流合同，不能据此推断服务器任意时长都支持。
- 时长输入优先按 `PrimitiveInt` / `PrimitiveFloat` 的节点类型判断，其余节点按原工作流数值推断。整数绑定要求范围内有整数秒，提交前拒绝小数。浮点绑定在面板中支持小数秒。
- 宽高同时绑定，必须是真正控制像素的数字输入。目标输入已有连线时，绑定连线会校验失败；应找到上游数字控制，或保持空白沿用工作流尺寸。
- 种子绑定数字输入。切换到另一个本地配置时使用该配置的宽高和种子默认值；同一型号重新选择保留手动编辑。
- 普通画布 JSON、缺失节点/输入、错误类型、重复绑定、无效时长及已知明文凭据输入在保存/提交前拒绝。

配置保存在本机应用 WebView 的 `comicBoxLocalComfyVideos`，不是 Git 共享文件；另存不含秘密的 API 工作流以便换机导入。保存失败不发布内存更新。损坏配置读取失败时保留原存储并禁止保存，修复配置并重启后恢复编辑。计划及任务记录包含工作流快照，后续编辑配置不改变原计划。2026-11-09 修复和验证见 [[排障/COMIC-BOX缺陷排查清单-2026-11-09]]。

## 提交与恢复

创作面板 → 通用 RunPlan → local-comfy → 既有官方 MCP `run_workflow(wait:false)` → 保存原 prompt ID/服务地址 → 官方 `job` 查询 → `fetch_outputs` → 应用私有暂存 → 项目媒体目录。应用不新增 `/prompt`、`/history`、`/view` HTTP 执行器。

任务恢复使用原 prompt ID，目标改变则要求恢复原连接，不重新提交。结果必须可读、成功保存后才标为已保存。私有工作流清理失败不能中断已接受任务的查询，也不能触发重新生成。

2026-11-10 起视频结果不再经 base64 回传：结果地址是私有输出文件的 asset 地址，有项目目录时由 Rust `comfy_mcp_copy_output_to_project` 流式复制进 `.raw/jc-media/视频/`（复用 UUID/outputs/扩展名校验，不覆盖已有文件）；无项目目录时仍用 `comfy_mcp_read_output`。结果地址校验只放行私有 outputs 下的媒体 asset 地址。图片结果不变。该改动尚未做真实 GPU 生成验收，变更记录见 `openspec/changes/stream-large-media-results/`。

## 实测问题与处理

1. 切换本地工作流沿用前一模型宽高/种子：已以回归用例复现并修复；仅切换型号时应用新配置默认值。
2. Windows 提交成功后，前端 fs 插件删除私有 workflow.json 被 scope 拒绝，原任务保留 ID、进入待恢复状态：改为与私有写入相同的 Rust 暂存边界。清理命令只接受 UUID、只删除对应 workflow.json；读取命令限定私有 UUID/outputs 下的媒体文件。未扩大通用文件 scope。清理异常改为保留文件并继续原任务。
3. 检查发现持久任务的计划摘要未带新工作流快照：补齐 `localWorkflow`，避免只有内存计划有快照。
4. 官方 CLI 在 Windows 返回扩展路径；前端字符串前缀比较把合法结果误判为越界：删除重复的字符串范围判断，唯一读取边界由 Rust canonicalize 后核对 UUID/outputs 和媒体扩展名，原任务恢复后成功读回、保存。
5. 应用重载后 MCP 设置显示空列表，但 SQLite 已有配置：MCP store 在 UI 优先挂载时过早读取未就绪缓存。改为先等待存储初始化、共享并发加载 Promise；恢复读取原配置及 enabled 状态，未覆盖为默认地址。
6. 自定义名称中的「·」后缀被旧云端型号缩写逻辑截断，无法区分精细版与快速版：本地自定义配置完整显示名称，旧云端名称规则保留。

观察到的未处理显示问题：手动「重新查询结果」遇到连接/读取异常时，旧公共任务界面会显示「生成失败」，即使 GPU 实际已完成；仍保留原任务 ID 和重新查询入口。本次原任务随后已查询成功。未把错误标题当作 GPU 失败，也未点重新生成。
