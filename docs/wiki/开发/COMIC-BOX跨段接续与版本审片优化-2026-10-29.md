# COMIC-BOX 跨段接续、版本审片与模型能力优化

## 范围与状态

用户授权四项通用优化：跨段首帧约束、生成版本对比恢复、按问题类型处理审片、准确读取模型能力。仅 Windows COMIC-BOX，保留累计用户改动、独立应用身份、原作、锁定资产与既有视频。不修改模型服务域名、插件、上传存储、签名、计费或发布配置。

本轮实现主要在程序调度、Vue 界面与原生媒体命令。Skill 继续负责专业创作方法；提示词中写“承接上一段”不能替代实际首帧参数。本轮未修改 Skill，也未为样片人物、灯位、固定景别或秒数添加产品特例。

## 四项行为合同

### 1. 跨段首帧约束

- 审片的“空间与接续”类别提供上一段切点尾帧预览，以及明确触发的“用上一段尾帧重做”。预览只做本地提帧；重做沿既有生成桥提交，是一次新的生成任务。
- 按上一段的计划截取长度、视频真实时长与帧率，在切点前一个帧间隔取图，不取模型额外生成、最终拼接会裁掉的尾部。变帧率素材的严格逐帧边界未单独验收。
- 首帧是独立用途。模型从显式首帧 asset slot、本地已登记首帧 API 或明确的 image_mode 枚举识别；不从型号名字猜能力，不把身份参考图自动改作首帧。
- 参考图与首帧可以并用时，有序参考图保持不变，首帧进入独立字段；互斥模式在提交前拒绝，不偷偷丢掉身份参考图。未声明支持的型号禁用重做按钮，并说明条件。
- 登记首帧的来源视频、任务、提示词指纹与切点。上一段换版或采用本地处理版后，旧首帧依赖过期，要求重新绑定或恢复对应来源，不自动创建下一段付费任务。

当前样片的 FK MiniMax H3 仅有参考图模式登记，未声明首帧支持；界面禁用绑定符合合同。本轮验证了真实本地尾帧提取、参数合同和失效逻辑，**未做支持型号的首帧云端生成验收**。

### 2. 版本对比与恢复

- 每段登记保留实际视频、生成输入、提示词全文、时长、参考绑定及来源类型的历史快照。旧库原有当前视频可在首次编辑前补快照；升级前已丢失的历史提示词不凭空补造。
- 对比弹窗按版本并排显示播放器和提示词，标明当前采用、模型生成或本地处理。
- “采用此版本”恢复提示词全文、正式检查点哈希和对应视频；不重新生成，不覆盖原始视频。保持累计提交计数，避免恢复后重用旧 requestId。
- 文件缺失、旧版本缺实际提示词快照、分段时间或参考绑定已改变、首帧来源过期时明确拒绝恢复；其他段保持。
- 审片键继续绑定实际采用的有序视频，换版后不能沿用其他视频的确认。历史版本与当前采用状态落在已有视频注册表，不新增平行任务系统。

### 3. 分类审片与本地处理

- 每段分别记录“剧情与表演”“空间与接续”“亮度与色彩”“声音”。剧情与接续意见可进入既有工程稿/提示词修改；色彩与声音分类不自动送进整集生成重做。
- 本地支持亮度、对比度、饱和度、冷暖、音量与静音。默认中性，显式操作后产出独立文件并登记为新版本；保留原视频，不做未经要求的自动匹配或自动静音。
- 处理使用现有 FFmpeg 运行时，固定参数和数值边界，不开放任意滤镜或命令。只处理当前窗口项目生成目录和应用派生目录下的视频，采用规范化路径，不覆盖输入。
- 原生命令复用已有媒体任务状态；此次实测发现该状态未注册，已补 `MediaCaptureJobs` 初始化。帧预览、派生视频和其他已用该状态的媒体工具共享同一实例。
- 处理方法依据 [FFmpeg 官方滤镜文档](https://ffmpeg.org/ffmpeg-filters.html) 的 eq、colorbalance、volume。声音语义、配音替换和自动画面质量判断不在本次能力中。

### 4. 模型能力读取

- 启动卡按当前选中型号读取完整参数档案，明确区分服务端目录和已有模型登记。切换型号后旧异步结果失效；等待或读取失败时不能启动。
- 统一解析时长枚举/范围、参考图 slot 与张数、比例、分辨率及首帧用途，保持服务声明的字段名和枚举大小写。比例/分辨率不兼容、缺时长合同或首帧专用型号不能直接代替整集参考生成时，提前说明并阻止启动。
- 云端与自定义文本端点共用容量字段解析，支持 contextWindow/context_window/context_length/top_provider.context_length 等已有标准字段，输出读取 maxOutputTokens/max_output_tokens/max_completion_tokens/top_provider.max_completion_tokens。仅接受有效正整数或整数值字符串，不把布尔、Infinity、价格和模型族名字当容量。
- 未声明的真实厂商容量仍是未知；此前 32768 输出兜底保持，不声称已替服务端补齐所有型号元数据。本轮没有服务端部署或收费能力核验。
- 异步失效处理参考 [Vue 官方侦听器清理机制](https://vuejs.org/guide/essentials/watchers.html#side-effect-cleanup)。
